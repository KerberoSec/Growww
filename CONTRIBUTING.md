# Contributing to Growww NBSE Monorepo

## Development Standards
- Standard ASCII hyphens exclusively (zero em/en dashes).
- Strict zero-PII logging standards compliant with DPDP Act 2023.
- Universal 0.00% Zero-Fee Invariant (No fee at all) distribution (0.00% fee at launch; future fee parameters governed by FeeController.sol).
- All Go code formatted via `gofmt` and checked via `golangci-lint`.
- All Rust code formatted via `cargo fmt` and checked via `cargo clippy`.
- All Python code formatted via `black` and checked via `ruff`.
