## Core Regulatory Invariants
1. **Zero-PII On Ledger:** No personal identifying data is ever written to blockchain state.
2. **100% Custodial Backing (1:1):** Every tokenized share, sovereign bond, or crypto asset is strictly backed 1:1 by real, unencumbered custodial assets.
3. **Mandatory Penny Drop Verification:** 100% beneficiary name match on all domestic banking deposits; third-party funding is strictly prohibited.
4. **Universal 0.00% (Zero Fee) Platform Fee:** Single deterministic fee model with automated 25% allocation to the Core Settlement Guarantee Fund (SGF).
