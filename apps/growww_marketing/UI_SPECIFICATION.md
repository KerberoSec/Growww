# Developer UI & Testnet Faucet Specification

## Public Components
- `TestnetFaucetModal`: Public interactive faucet dispensing 10,000 vUSDT and 1 vBTC to entered testnet wallet addresses.
- `SolvencyVerifierWidget`: Client-side WebAssembly tool computing Poseidon hashes to verify liability tree inclusion.
- `APIConsole`: Interactive REST and WebSocket subscription tester with syntax-highlighted code snippets.
