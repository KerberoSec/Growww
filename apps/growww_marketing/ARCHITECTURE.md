# Architecture & Developer Portal Specification

## Executive Overview
`growww_marketing` is the public-facing landing portal and developer documentation platform providing zero-barrier access to platform specifications, APIs, and testnet faucets.

## Key Capabilities
- Static site generation (SSG) with incremental static regeneration (ISR) for sub-500ms page loads globally.
- Interactive OpenAPI 3.0 Swagger sandbox allowing algorithmic traders to test REST and WebSocket feeds.
- Public WebAssembly Merkle Tree Verifier allowing any user to verify balance inclusion in zero-knowledge.
