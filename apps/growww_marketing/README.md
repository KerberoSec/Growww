# Growww Public Landing & Developer Documentation Portal

## Purpose & Scope
`growww_marketing` is the public-facing landing portal, product showcase, and developer documentation hub for the Growww / NBSE trading ecosystem.

## Key Sections
- **Public Showcase**: Highlighting zero-counterparty risk, on-chain DvP settlement, and 24/7 BTC/USDT trading.
- **Interactive Testnet Faucet**: Public web interface allowing new developers to claim 10,000 vUSDT and 1 vBTC.
- **Developer API Docs**: OpenAPI 3.0 interactive documentation for REST, WebSocket, and FIX protocol endpoints.
- **Proof-of-Solvency Portal**: Public Merkle tree verifier where users verify balance inclusion in zero-knowledge.
