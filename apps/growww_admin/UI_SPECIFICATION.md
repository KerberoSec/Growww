# Admin UI Component & Dispute Workflow Specification

## Workstation Views
- `DisputeDetailDrawer`: Side-by-side comparison of buyer bank payment receipts and seller claims.
- `ReserveHealthCard`: Real-time gauge displaying solvency ratio (>102% threshold).
- `EmergencyHaltModal`: Dual-authorization prompt requiring two senior risk officer approvals to trigger market circuit breakers.
- `AuditLogViewer`: Searchable timeline of all system events with cryptographic signature verification.
