# Security Policy & Vulnerability Disclosure

## Supported Versions
| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability
The Growww NBSE engineering team takes security vulnerabilities seriously.

- **Security Email:** security@growww.internal
- **PGP Key ID:** 0x4B3A89F2
- **SLA for Acknowledgement:** 24 hours
- **SLA for Remediation Plan:** 72 hours

Please do not disclose security issues publicly before a coordinated release is published.
