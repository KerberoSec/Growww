# Web UI Design System (Next.js & Tailwind)

## Purpose & Scope
`packages/web_ui` provides reusable React components, Tailwind CSS plugins, and design tokens for web trading terminals.

## Component Inventory
- `OrderbookTable`: Zero-layout-shift tabular price display with microsecond tick flashes.
- `TradingViewWrapper`: High-performance canvas bridge for TradingView Advanced Charts.
- `WindowDock`: Detachable multi-window layout container supporting multi-monitor day trading.
- `StatCounter`: Odometer-style animated numerical counter for portfolio values.
