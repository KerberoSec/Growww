# Growww UI Design System (Flutter)

## Purpose & Scope
`packages/growww_ui` is the shared Flutter design library implementing the Obsidian Dark Mode theme, custom trading widgets, and tactile animation primitives.

## Component Inventory
- `ObsidianTheme`: Semantic color tokens (`#0B0E14` canvas, `#00F0A0` neon green, `#FF3B56` neon red).
- `OrderbookLadder`: High-performance CustomPainter Level 2 depth ladder with background volume heatmaps.
- `PercentageSlider`: Smooth 0-100% balance allocator with 25%, 50%, 75%, 100% quick chips.
- `HapticFeedbackEngine`: Tactile vibration triggers for order submission, fills, and errors.
